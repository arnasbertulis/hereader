# Security Policy

## Supported versions

Solo project — only the latest [release](https://github.com/arnasbertulis/hereader/releases),
the one deployed at hereader.arnasbertulis.com, is supported. Fixes land on
`main` and ship in the next release.

## Reporting a vulnerability

Open a [private security advisory](https://github.com/arnasbertulis/hereader/security/advisories/new)
on this repo (GitHub Security tab → "Report a vulnerability"). Do not open a
public issue for suspected vulnerabilities.

This is a solo portfolio project with no SLA. Reports are triaged and fixed
on a best-effort basis; no guaranteed response time.
